# Publish Reviews

This folder stores the durable, cross-post archive of publish reviews.

- Use one markdown file per published post.
- File name pattern:
  `YYYY-MM-DD-<slug>.md`
- Keep the full case workspace in `demo_posts/<date>-<slug>/` when useful.
- Mirror the durable review back into `hypo.md` when the learning affects story structure or workflow.
