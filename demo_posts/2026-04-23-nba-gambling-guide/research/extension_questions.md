## Q1 · 为什么会有单人数据赌盘？

### 短答
因为传统三件套（胜负 / 让分 / 大小分）的毛利已经被卷平。博彩平台要差异化、要粘住用户、要把看 48 分钟比赛的人留下来下更多注——**单人数据市场就是这门生意的「产品创新」**。

### 展开（3 条动力）

1. **需求侧**：普通赌客不满足于「谁赢」那一注。一场比赛有 2-3 小时，胜负盘只有一个结果，中间 47 分钟没事可干。单人市场把「你最喜欢的那个球员今晚能不能拿 25 分 / 抢到 8 个篮板 / 投进 3 记三分」变成可下注事件，把**一场比赛切成了几十个下注机会**。对平台来说这叫「增加 handle（下注总量）+ 延长会话时间」。

2. **供给侧**：sportsbook 的毛利在胜负盘上只有个位数，但在 parlay（多注串起来）和单人 prop 上可以做到两位数。越精细的市场、越难精确定价的市场，理论 edge 越大。平台要赚钱就得往精细走。

3. **技术侧**：2010s 中期开始实时数据 + 手机 app 普及，in-play（滚球）下注成为可能。**你能在第三节中场看当前某球员已经几个篮板，决定要不要押他这场篮板 over 10.5**—— 这种玩法没有实时数据喂养是做不出来的。Sportradar、Genius Sports 这些数据商就是这条供应链的核心。

### 进可发的一句
> 「切得越细越赚钱——但切到单人就切到了整条监管防线的最薄处。」

## Q2 · 是谁开的？

### 短答
**不是 NBA 开的，是 sportsbook operator 开的**；喂数据的是数据商；NBA 把数据授权卖给数据商，**从头部拿一道过路费，不决定哪条线画在 2.5**。

### 展开（数据链三层）

```
NBA 联盟
  └─ 独家 official data rights 授权给 → Sportradar（主）+ Genius Sports
                                         └─ 分发给 → DraftKings / FanDuel / BetMGM / Caesars / ESPN BET
                                                     └─ 这些 operator 才是真正开市场、画线、收下注的人
                                                        └─ 把市场推给 → 终端用户
```

### 三类玩家

1. **联盟层 NBA**：卖 data rights、靠赞助和媒体合作分一杯（前篇 8.94 亿赞助里就有 DraftKings + FanDuel）。**不直接决定单条市场的线在哪**。
2. **数据商 Sportradar / Genius Sports / Kambi**：喂实时数据给 sportsbook、做 odds 模型、跑异常下注监控（前篇「三道防线」第二道）。
3. **sportsbook operator**：DraftKings、FanDuel、BetMGM、Caesars、ESPN BET（Penn Entertainment）、Fanatics Sportsbook。**他们才是决定「Beasley 这场篮板 under 2.5 赔率怎么开」的那批人**。

### 关键误区纠正
> 「NBA 开的赌盘」是误读。NBA 的角色更像「房东」—— 它租出去的是比赛的数据权和场边广告位，不是每一条市场的定价权。

## Q3 · NBA 合法 vs 非法赌博市场 差异在哪？

### 短答
合法市场的「脆」是产品结构（单人市场门槛低 + 在监管视野内被抓）；**非法市场的「脆」是整个盘口不在任何监管视野中**。两种「脆」是两个完全不同的问题。

### 核心差异对照

| 维度 | 合法市场 | 非法市场 |
|---|---|---|
| 牌照 | 州博彩委员会发牌 | 无牌 / 离岸牌照 |
| 身份验证 | KYC 实名 + 银行卡 | 匿名 / 加密货币 |
| 资金追溯 | 受反洗钱法 AML 约束 | 基本不可追 |
| 监控 | 异常下注 report 上游 | 无 report 义务 |
| 税收 | 正规抽税（NBA 间接受益）| 零税 |
| 催收 | 法律流程 | 暴力 / 恐吓 |
| 对 NBA 球员开放？ | 联盟禁赌，账户会被平台拒 | 代理人 / 朋友代下就行 |
| 2022 年美国规模 | 约 $1000 亿下注量（当年） | AGA 估 **$510 亿**非法规模 |

### 三条关键观察

1. **合法市场看起来干净，但 NBA 禁赌条款反而把球员推进非法市场**。因为合法平台有 KYC 能查到球员本人，所以想下注的球员（或接受贿赂操纵自己数据的球员）必须走代理人或地下盘。Porter 案的资金流就是合法端（被监控挖出来）和非合法端（朋友代下）双轨并行。

2. **非法市场在大案中的角色**：前篇 2025.10.23 同日被捕的 Billups / Rozier / Damon Jones，背后是四大纽约黑手党家族（Bonanno / Gambino / Lucchese / Genovese）开的**地下扑克局 + 地下体育盘**，用假洗牌机、X 光扑克桌、加密货币洗钱、暴力追债。受害者总损失至少 $700 万（前篇 fact_pack 已口径）。这不是合法市场的问题，这是司法问题。

3. **监管套利**：非法离岸平台（Bovada 等）对美国用户技术上非法但实际可访问。2018 PASPA 推翻前，这些离岸平台养了几十年的用户习惯；合法化后部分用户没回流，因为离岸赔率更好 + 可匿名 + 可下联盟禁止的市场（比如直接赌大学生个人数据）。

### 进可发的一句
> 「联盟自己踩的那条线是『球员不能下注』；结果把球员推到了一条连联盟都够不着的线上。」

## Q4 · NBA 有无审核机制？

### 短答
有，但**不是「审市场」，是「审合作方 + 审球员行为 + 审异常事件」**。NBA 不直接决定哪条市场上架或下架，但可以通过 integrity agreement 条款施压。

### 四个审核层面

1. **审合作方**（Gaming Compliance 部门 / 名字可能略异）
   - Sportsbook operator 要成为 NBA 官方合作伙伴必须通过 vetting：资本充足性、合规纪录、KYC 能力、数据对接
   - DraftKings / FanDuel / BetMGM 都是这套流程下来的
   - 数据商 Sportradar 有 NBA 独家授权，一旦出整合性漏洞，整条数据链都得审

2. **审球员 / 教练行为**（每季度常规动作）
   - 每季反复播放禁赌教育视频
   - 每 offseason 签禁赌承诺书
   - 接到试探必须通过 2023 起设置的匿名 tip line 报告
   - 球员 / 家人 / 经纪人 / 助理教练全部在禁赌名单内
   - 处罚阶梯：罚款 → 停赛场次 → 长期停赛 → 终身禁赛 → 移交联邦

3. **审异常事件**（被动触发）
   - Sportradar / Genius Sports 把跨平台异常下注打包 report 给 NBA integrity 部门
   - NBA 决定是否启动内部调查、是否移交联邦
   - Porter 就是这条路径跑完的：异常报告 → 内部调查 → 移交联邦 → 2024.4.17 终身禁赛
   - Rozier 2023 年第一次触发时 NBA 自查后放过，直到 2024 年 FBI 从外部启动才又回到审核视野

4. **审「哪类市场该存在」**（能影响但不强制）
   - NBA 和 sportsbook 签 integrity agreement 里有条款：
     - NBA 可以 request 下架特定 bet types
     - NBA 可以 require incident reporting
     - NBA 最初想要 1% 「integrity fee」（多数州立法没通过）
   - 2025 年起 DraftKings / FanDuel 下架部分低薪轮换球员 under 市场，一部分是 operator 自觉，一部分是 NBA 施压
   - 但 NBA **无法强制所有市场下架**——这是 operator 商业决定 + **州 regulator 最终说了算**

### 关键结论
> NBA 的「审核」像房东看租客的行为，不像市监局决定货架上摆什么。第三道防线（operator 自查）对 NBA 来说是合作方自愿配合，不是 NBA 的强制权。
