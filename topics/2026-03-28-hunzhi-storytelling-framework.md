# 混知圖片說故事架構提煉

> 關注點：**怎麼用圖說故事**，不關注美術風格
>
> 陳磊原話：「漫畫只是表象，更重要的是漫畫背後的知識邏輯和敘述策略，這才是核心。」

---

## 一、核心公式

```
知識痛點（What）
× 學渣視角（Who）— 倒數第二教倒數第一，深知同病相憐的痛點
× 生活比喻（How）— 把看不見的變看得見
× 段子節奏（Feel）— 先塞內容，再塞梗
= 混知爆款
```

三化原則：**脈絡化 → 圖像化 → 娛樂化**（按順序做，不能倒著來）

---

## 一B、三段式創作流程（比公式更具體）

這是混知在製作每一篇內容時走的三步：

### 第一步：戰略藐視（建立讀者信心）
**在解釋任何東西之前**，先告訴讀者「這個看起來難，其實不難」。
不從複雜度開始，而是從「打消讀者對這個主題的恐懼」開始。

### 第二步：生活聯想（找轉換器）
把抽象概念立刻映射到一個熟悉的日常場景。
規則：*「借助生活語言、生活場景做轉換器」*
場景不需要完全精確，只需要激活讀者已有的心智模型。

### 第三步：知識串聯（用邏輯穿針引線）
知識是珍珠，邏輯是線。
每一顆珍珠（事實）只有在穿在因果鏈這條線上，讀者才記得住。
**生產時間分配**：畫圖只佔 20%，前期選題 + 研究 + 找比喻 = 80%。

---

## 二、單張圖的最小單位

每一格 = **一個認知衝擊**，結構如下：

```
[設定情境] → [打破預期] → [角色用表情/動作確認衝擊]
```

例：
- 設定：兩棟樓，左矮右高（正常預期：右邊更好）
- 打破：標出「右樓地板 = 左樓頂層」（反常識）
- 確認：小人站中間，嘴巴張開，手指指向兩者齊平線

**角色表情是必須的**——它是讀者的「替身」，替讀者先做出反應，告訴讀者「這裡應該驚訝」。

---

## 三、多圖序列的敘事邏輯

### 層層抽絲剝繭模型（四格版本）

```
圖1：鉤子      — 反常識事實 / 震驚數字 / 強烈對比
                目的：讓人翻到圖2（不是讓人理解，是讓人好奇）

圖2：放大矛盾  — 把圖1的衝擊展開，但不給答案
                技巧：用空間/物理比喻取代數字表格
                目的：讀者開始問「為什麼」

圖3：揭示真相  — 否定常識誤區 → 給出真正原因
                技巧：「大家以為是X，其實是Y」句式
                目的：產生「原來如此」的頓悟感

圖4：落點收口  — 現實意義 / 未來走向 / 互動問題
                技巧：留一個「選邊站」的開放問題
                目的：引發評論，延長內容生命週期
```

### 關鍵原則：每張圖只做一件事

混知最常見的失敗（別人模仿時的錯誤）是把兩件事塞進一格。
正確做法：**一格 = 一個問題 or 一個答案，絕不同時出現**。

### 珍珠串模型（Pearls on a String）

每一個段落用「一個主幹概念」作為主線，其他事實從它向外延伸。
- 主幹 = 線（因果邏輯）
- 事實 = 珍珠（附著在線上才有意義）

讀者只需記住「線」，珍珠自然跟著來。
應用到我們的帖：主線 = 「WNBA 虧了 29 年，版權費撐不起薪資」，其他數字（Clark $78K、轉播費 $2億）都是這條線上的珍珠。

### 邏輯漏斗（寬 → 窄）

序列永遠從寬到窄：
```
宏觀背景 → 核心矛盾 → 具體事件 → 後果 → 你能怎麼看
```
先給方向感，再給細節。讀者不會在圖2就棄翻。

## 三B、圖與圖之間的轉場技法

### 因果轉場（最常用）
「因為X → Y發生了 → 導致Z」
純時序轉場（「然後…然後…」）被刻意避免，因為不產生「必然感」。

### 「等一下，但如果…」轉場
每一個段落收尾時，混知會搶先說出讀者最可能有的下一個問題：
> 「好，你可能想說——那誰誰誰呢？」

這讓讀者感覺「作者在我腦子裡」，信任感和繼續讀的動力大增。

### 壓縮—釋放節奏
- **壓縮**：連續幾格快速遞進、張力升高
- **釋放**：一個寬格、一個梗，或一個大頓悟

節奏是：緊緊緊 → 鬆。不能一直緊，讀者會疲勞。

## 四、抽象數據的視覺化原則

### 問題診斷

| 原始處理 | 為什麼不夠好 |
|---------|------------|
| 數字表格 | 需要眼睛比對，不觸發情緒 |
| 條列原因 | 平行結構，沒有因果張力 |
| 百分比圖表 | 需要背景知識才能判斷「這大還是小」 |

### 混知的解法：空間化 / 物理化

把數字變成**可以在空間裡感知的東西**：

| 抽象概念 | 混知轉化方式 |
|---------|------------|
| 疆土大小 | 房子大小 |
| 朝代更替 | 住客換人 |
| 薪資差距 | 錢袋大小對比 |
| 舊天花板 = 新地板 | 兩棟高度不同的樓，齊平線 |
| 版權費增長 | 水管流量 → 水庫水位上升 |
| 複雜歷史脈絡 | 小人之間的空間關係（合租、佔領、驅逐） |

**核心轉化句型**：「如果把 [抽象事實] 比作 [日常物件]，那就是……」

### 數字呈現的三層次

```
第一層（最差）：直接顯示 $78,066 vs $78,831
第二層（中等）：用圖表顯示差距
第三層（混知式）：兩個人拿一樣大的錢袋，旁邊角色指著說「等一下……」
```

第三層的關鍵：**讓讀者自己發現差異，而不是被告知**。

---

### 轉換器的有效條件（Converter Rules）

找到生活比喻之後，混知有三個篩選標準：
1. **立刻能被非專家識別**（不能用另一個陌生場景解釋陌生概念）
2. **結構上精確同構**（比喻的邏輯關係要和真實概念的邏輯關係一致，不能只是表面像）
3. **最好有點好笑或出乎意料**（光是「描述性」的比喻不夠，需要帶驚喜）

轉換器在序列的**開頭就引入**，整段內容用同一個比喻的語言寫，讀者不用切換框架。

**已知的具體案例**：
- 戰國七雄 → 一個班級，班霸、學霸、無力的班主任
- 封建經濟 → 公司組織架構（HR、實習生、不聽話的CEO）
- 碳交易 → 遊戲內的虛擬貨幣市場
- 免疫系統 → 工廠生產線 + 保全 + 警報系統
- 金融危機連鎖反應 → 倒骨牌

## 五、開頭鉤子的三種類型

混知的鉤子公式：**先建立讀者的常識預期，再用幽默方式打破它**。

典型兩拍結構：
- **拍1**：說出讀者「以為自己知道」的版本
- **拍2**：立刻推翻，帶出真實的有趣面

陳磊談孔子那篇：「孔子，大家心目中的聖人……溫文爾雅……不過，這老夫子其實也不是個省油的燈！」→ 讀者降低戒心，然後好奇心被勾起。

### 類型 A：反常識事實型
> 「她打出了44分新人紀錄，球隊給她的薪水是……$78,000。」

特徵：正面資訊（成就）+ 反面結果（極低回報），形成落差。

### 類型 B：強烈對比型
> 「這兩個數字，哪個更大？$1,272,870 vs $78,066。」

特徵：把讀者已知概念（NBA薪資）和未知（WNBA薪資）放在一起，用比例衝擊。

### 類型 C：懸念問題型（框架式鉤子）
標題格式：「如果把 [複雜事物] 比作 [熟悉場景]，這事就好理解了」
> 「如果東周列國是一個班級，這事兒就好理解了」

特徵：在標題就把比喻框架和理解承諾一起給出，讀者知道「翻完我就懂了」。

### 低門檻承諾型
用最少的字給出最直白的解釋：青蒿素那篇開頭只用了三個字「**餓死它**」（殺瘧疾的方法）。
鉤子是：「這比你以為的容易理解。」

## 六、讓人「看完」的設計邏輯

研究發現混知有幾個讓完讀率極高的機制：

### 懶人目錄（開頭給地圖）
在序列開頭放「你將看到什麼」的視覺目錄。
**看起來會讓人懶得翻，但反而提高完讀率**——因為讀者感覺「旅程有邊界、我能控制進度」。

### 每章有小結局
每個段落以清晰的小結論收尾，不在段落中留懸念。
讀者得到「段落級滿足感」，才願意繼續翻下一格。

### 「你能說給別人聽」承諾
混知的目標：讓讀者看完後「說得出」。
整個序列結構讓讀者覺得自己**在逐步成為這個話題的懂行者**。
這種「變強的感覺」本身就是鉤子。

### 結尾三要素
```
① 首尾呼應（回到開頭的設定）
② 一句金句（最核心洞察，能截圖轉發）
③ 互動問題 or 下期預告
```

---

## 七、結尾互動的設計邏輯

混知結尾不是「總結」，而是「留下一個未解的問題」。

**有效互動問題的三個條件**：
1. **沒有明確正確答案**（有明確答案就沒有評論動機）
2. **和讀者的立場有關**（「你會選哪個」比「你知道嗎」好）
3. **非常容易回答**（A/B/C 選擇 > 開放填空）

**我們的WNBA版本**：
> 「Clark 和 Bueckers，誰先拿超頂薪？你站哪邊？A. Clark B. Bueckers C. 會一起拿」

---

## 八、「否定誤區」節奏的完整句型

這是混知製造「頓悟感」最常用的句式結構：

```
大家以為：[常見認知/直覺答案]
↓
但其實：[真正原因]
↓
所以：[重新理解世界的視角]
```

應用到我們的WNBA帖：
```
大家以為：WNBA薪資低是因為「女籃不如男籃」
↓
但其實：是因為聯盟虧損了29年，版權費根本撐不起薪資
↓
所以：不是球員不夠好——是水庫29年才蓄滿
```

## 九、圖與圖之間的轉場邏輯（總覽）

混知的多格圖不是「獨立圖片」，是**推理鏈**：

```
圖1 → 圖2：「你看到的現象」→「但你不知道的是」
圖2 → 圖3：「問題擺在這裡」→「原因在哪裡」
圖3 → 圖4：「現在你懂了」→「那你怎麼選」
```

每個轉場都是一個**認知升級**，讀者翻頁等於「我變得更懂了一點」。
這就是為什麼人會翻完——不是美圖吸引，而是**不翻完就覺得虧了**。

| 圖2 | 空間化數字，不用表格 | 兩棟樓，舊頂 = 新底 | ✅ |

## 十一、完整架構總覽表

| 層次 | 技法 | 核心原則 |
|------|------|---------|
| **開頭** | 預期 → 反轉鉤子 | 降低戒心，製造好奇 |
| **論證結構** | 因果鏈（非時序） | 邏輯優先於時間軸 |
| **概念轉化** | 生活場景轉換器 | 結構同構，不只是表面像 |
| **數據處理** | 比例 + 身體感知比喻 | 比例感 > 精確數字 |
| **張力** | 認知缺口 + 壓縮釋放節奏 | 驚喜感 + 韻律 |
| **頓悟感** | 「原來如此」時刻 + 幽默釋放 | 讓讀者感覺「變強了」 |
| **完讀率** | 每章小結局 + 懶人目錄 + 「說得出」承諾 | 旅程有邊界 |
| **轉場** | 因果連結 + 「等一下但是…」預判 | 讀者感覺作者在他腦子裡 |
| **結尾** | 首尾呼應 + 一句金句 + 互動問題 | 關閉感 + 可分享性 |
