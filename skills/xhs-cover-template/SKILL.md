# XHS Cover Template

这个 skill 先做一件事：在首图阶段快速确认封面有没有站住。

默认要先过一次简版 `cover check`：

- 主角
- 动作
- 冲突
- 背景符号

如果这 4 项都清楚，而且仍在账号预设结构内，就直接把检查结果交回 `xhs-note-assembly` 继续往下走。

只有在以下情况，才需要把这个 skill 从“快速检查”升级成“替代封面探索”：

- 封面明显偏离账号预设结构
- 用户明确说”先锁封面模板”或”这次封面要换结构”
- 这篇不适合人物封面，需要探索替代方案
- 用户说”首图文案太多 / 太乱 / 不够一眼懂”

## 账号预设封面结构

默认只有三层，从上到下：

1. **标题区（最多两行）**
   - 超大判断句或数字，做第一视觉中心
   - 必须比人物脸更先抓眼
   - 标题从 `xhs-note-assembly` 成稿中直接带入，不在封面步骤重新想
2. **人物区**
   - `1 个` 可辨识脸部的人物主角，优先半身到大腿中段构图
   - 不是剪影，不是 tiny figure，不是纯概念物件
3. **场景背景**
   - 深色场景底，优先球馆、场馆、屏幕、看台这类”这是体育现场”的符号
   - 人物要有场景关系：球、球馆、屏幕、看台、地板线，至少保留 2-3 个
   - 不做纯色人物卡

不要有背景说明小字。封面只靠标题和人物两个元素拦停。

### 封面字体与标题限制

字体：
- 统一使用 `阿里巴巴普惠体 Bold/Heavy`
- 全帖封面只用这一个字体家族，靠字重区分层级
- 不用宋体、手写体、书法体、圆体

标题限制：
- 最多两行
- 每行不超过 `8` 个字
- 如果塞不进两行，砍字，不要缩字号

对比要求：
- 深色背景 → 白字或亮色字
- 亮色背景 → 深色字 + 投影或描边
- 标题和背景色不能接近，必须一眼可读
- 图上文字一律简体中文，除非是无法翻译的专有名词

### 封面生图规则（AutoResearch 验证，30 轮 + 人工验证）

以下规则来自封面 prompt A/B 实验，53% 改善率后收敛：

**最有效的变量**：
- **具体动作描述 > 抽象 hero pose**：把”英雄站姿”换成可视化的运动瞬间（三分出手 follow-through、tunnel walk 入场），效果立竿见影
- **emotional_conflict 是最值得投入的变量**：优先选”当下有个人故事高峰”的人物，而非纯战绩驱动
- **攝影语言**（景深、调色）性价比最高：只改”怎么拍”不改内容，AI 理解度高

**硬边界**：
- **品牌调性不可违背**：冷蓝霓虹、dutch angle、脆弱沉思情绪都因偏离知性定位被拒
- **抽象背景 > 写实背景**：AI 画人群容易翻车，能量粒子+烟雾既安全又有质感
- **减法全部失败**（删元素 0% 胜率）：每个组件都在贡献，prompt 无冗余
- **极端化危险**：虫视角拿到全场最低 2/6，过犹不及
- **标志性道具不应作为光晕/装饰层**：背景必须服务主角，不能抢戏

### 预设封面更适合

- 人物带动价值变化
- 薪资、商业、破圈、估值、转播这类”某个人改写了什么”的题
- 需要让用户一眼看到人脸、数字和场景三件事

### 不走预设封面

触发条件（任一成立）：
- 没有明确人物主角（纯规则题、纯数据题）
- 题目本质靠证据截图成立（转播画面、官方公告）
- 用户明确说不要人物封面

不走预设时，封面结构需要重新探索。以下是几个可参考的方向：

**方向 A：标志性物件 + 大数字**
例：奖杯、球鞋、合约文件 + 金额或倍数
适合：规则变化、联盟扩张、金额对比

**方向 B：场馆/屏幕 + 判断句**
例：空场馆全景、转播画面、平台界面
适合：转播权、平台战争、现场事件

**方向 C：数据海报（极简排版）**
例：数字结构是主角，人物不出现或极小
适合：纯排名、时间轴、多方对比

这些方向不是固定模板，需要根据具体题目探索。
字体和对比规则不变。

## 工作流

默认先做一次快速检查；只有检查不通过时，才进入替代封面探索。

### 0. 先过简版 cover check

- 主角是谁
- 动作是什么
- 冲突在哪里
- 背景符号是什么
- 这 4 项里如果有 `2` 项以上说不清，就不要直接开始生图
- 第一轮不要从“人物 + 数据背景”的静态模板起手

### 1. 确认为什么不走预设

- 是没有人物主角？
- 是用户主动要换结构？
- 还是预设结构不适合这个题？

### 2. 锁封面任务

封面只做一件事：拉点击、讲一个结论、或放大一个数字。

### 3. 锁主角

- 如果有人物：只能有一个绝对主角，优先人物
- 如果没有强人物：参考上方”不走预设封面”的方向 A/B/C
- 不要为了满足模板而硬生成人脸

### 4. 确认标题

- 标题从 `xhs-note-assembly` 成稿中带入
- 检查是否符合两行限制（每行不超过 8 字）
- 如果成稿标题太长，在这步砍字

### 5. 给下游交接

交给 `xhs-image-style-duo` 的应该是：

- 主角说明
- 构图说明
- 文字安全区
- 画面情绪

## 不要这样做

- 不要把封面写成一整段话
- 不要让首图同时讲人物、机制、证据三层
- 不要先换画风，再想封面要卖什么
- 不要堆英文和小字
- 不要加背景说明小字，封面只靠标题和人物拦停
- 不要在这步重新想标题，标题从成稿带入
