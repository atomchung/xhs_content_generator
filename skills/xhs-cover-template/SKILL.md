# XHS Cover Template

这个 skill 只做首图封面模板。

它的任务是把图 1 锁成一个稳定的商业新闻封面系统：

- 一个绝对主角
- 一句短主文案
- 一个最大数字或判断
- 清楚的文字安全区

不要在这一步决定整组图片分工。那一步交给 `xhs-visual-asset-mix`。  
不要在这一步细调具体画风。那一步交给 `xhs-image-style-duo`。

## 什么时候用

- 用户说“先做首图”
- 用户说“要大人物大字封面”
- 用户说“给我一个稳定封面模板”
- 用户说“封面像商业新闻”
- 用户说“首图文案太多 / 太乱 / 不够一眼懂”

## 默认模板

默认只用这一套：

- `1 个` 主角，占画面 `60-70%`
- `1 句` 主标题，优先 `6-12` 个简体中文
- `1 组` 最大数字或判断词，做第二视觉中心
- 深色背景 + 亮色文字 + 少量强调色
- 上下或左右保留清楚文字安全区

## 工作流

### 1. 先锁封面任务

封面通常只做一件事：

- 拉点击
- 讲一个结论
- 放大一个数字

### 2. 再锁主角

- 只能有一个绝对主角
- 如果这篇是人物带动行业变化，主角优先是人物，不是机制图
- 如果这篇没有强人物，优先回退到标志性物件或场馆

### 2.1 如果没有强人物

- 优先回退到 `标志性物件 + 大数字`
- 或 `场馆 / 屏幕 / 平台界面 + 判断句`
- 不要为了满足“大人物封面”而硬生成人脸

### 3. 再写封面字

默认只保留两组文字：

- 主标题
- 最大数字 / 判断句

要求：

- 优先简体中文
- 尽量不用英文缩写
- 不写长句
- 数字能不用小数就不用小数

### 4. 最后给下游交接

如果封面要生图，交给 `xhs-image-style-duo` 的应该是：

- 主角说明
- 构图说明
- 文字安全区
- 画面情绪

## 输出格式

```markdown
## 封面任务
- 这张图要卖什么：
- 为什么值得放首图：

## 模板锁定
- 主角：
- 构图：
- 文字安全区：
- 背景层级：
- 配色方向：

## 封面文案
- 主标题：
- 最大数字 / 判断：
- 备选短句：

## 交给后续技能
- 给 `xhs-image-style-duo` 的画面 brief：
- 给设计 / 排字的限制：

## 需要人拍板
- 主角是否正确：
- 主标题是否够短：
- 数字是否够大：
```

## 不要这样做

- 不要把封面写成一整段话
- 不要让首图同时讲人物、机制、证据三层
- 不要先换画风，再想封面要卖什么
- 不要堆英文和小字
