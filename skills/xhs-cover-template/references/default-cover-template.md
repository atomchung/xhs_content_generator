# Default Cover Template

这份参考只定义默认首图模板，不负责具体画风。

## 默认版式

- 竖版 `3:4`
- 一个主角，占画面 `60-70%`
- 背景压到第二层，只留 `2-3` 个环境符号
- 文字区不要切到脸和关键手势

## 默认文字层级

第一层：
- 人名 / 联盟 / 年份

第二层：
- 最大数字
- 或一句最短判断

## 适合的题

- 人物带动商业变化
- 薪资、版权、扩军、转播这类商业新闻
- “某个人改写了什么” 的题

## 不适合的题

- 纯机制题，没有主角也没有强物件
- 需要同时讲很多数字的信息图
- 证据截图才是核心的题

## 默认配色

- 深蓝或深灰做底
- 白色做主文字
- 亮黄、亮橙或红色做强调

## 默认判断

先问这三句：

- 不懂体育的人能一眼知道主角是谁吗？
- 这张图有没有只卖一个结论？
- 图上的字删掉一半之后，会不会更强？
