# Clark Cover Structure

参考封面：

- `2026-03-28`
- `🏀 WNBA 好日子来了？克拉克薪水暴涨7倍`

这张封面的可复用结构不是“Clark 本人”，而是下面这套层级：

## 视觉层级

1. 红色外框
2. 深色球馆背景
3. 顶部小字交代背景
4. 中上部超大判断 / 数字
5. 下半部分可辨识脸的人物近景
6. 球馆、看台、记分牌、球等场景符号补齐“这是体育现场”

## 默认版式

- 竖版 `3:4`
- 上方 `35-45%` 给文字
- 下方 `55-65%` 给人物和场景
- 人物脸要清楚，不做 tiny figure
- 背景不要抽象到看不出项目

## 默认文字结构

- 小字：
  `年份 / 人名 / 事件`
- 大字：
  `最大数字 / 最短判断`

例子：

- 小字：`2026 克拉克收入`
- 大字：`暴涨 7 倍`

## 适合的题

- 人物带动价值变化
- 收入、代言、估值、薪资、版权、扩军
- 用户需要“一眼知道是谁 + 发生了什么 + 数字多大”

## 不适合的题

- 没有人物主角
- 纯规则解释
- 证据截图本身比情绪封面更重要
