# XHS Note Assembly

这个 skill 负责把前面已经锁好的内容组装成一篇可发的小红书帖子。

前提：
- 角度已经基本确定
- fact pack 已经有了
- 图片分工已经清楚

如果前提不成立，先回到前面的 skill，不要硬写。

## 什么时候用

- 用户说“现在写成稿”
- 用户要标题、正文、图上文案一起出
- 用户要 3-4 张图的故事板
- 用户要把前面讨论整理成最终笔记

## 组装原则

### 1. 正文结构要短，但论点链不能断

推荐 3 到 4 个问题块：
- 发生了什么
- 为什么这样做
- 为什么大家在吵
- 现在看值不值 / 该怎么判断

### 2. 标题先抢打开率

标题优先顺序：
- 争议
- 问题
- 人名 / 赛事
- 数字

### 3. 图文分工要互补

- 图上讲最直观的东西
- 正文讲“为什么”
- 来源沉到底部

### 4. 保留互动收口

收口不要问太空泛的问题。

优先用：
- 三选一
- 会 / 不会
- 值 / 不值
- 你站哪边

### 5. 人工最终拍板

默认由人类决定：
- 最终标题
- 封面方案
- 删掉哪些过重的解释

## 输出格式

```markdown
## 标题候选
1. ...
2. ...
3. ...

## 最终标题
- ...

## 正文
- ...

## 图组
### 图 1
- 任务：
- 图上文案：
- 画面说明：
- prompt / 素材说明：

### 图 2
...

## 参考来源
- ...

## 需要人拍板
- 标题：
- 封面：
- 删减：
```

## 不要这样做

- 不要重新发明角度
- 不要把 fact pack 原封不动贴进正文
- 不要一边写成稿一边重新定义每张图的任务
- 不要把所有信息都塞进标题和封面
