# Note Assembly Examples

这份参考不是让你照抄句子，而是看结构差异。

## 好例子：先判断，再分段

开头：
- 先说一句总判断
- 不绕背景

正文：
- `2-3` 个完整小段
- 每段只讲一件事
- 每段前半句尽量有数字、变化或反直觉事实

收尾：
- 先落一句判断
- 再抛互动问题

## 常见失败 1：像资料整理稿

问题：
- 一上来先补背景
- 段落太长
- 重要数字埋在中后段

改法：
- 把第一句改成判断句
- 删掉一半背景
- 让每段开头就出现最重要的信息

## 常见失败 2：像体育媒体，不像小红书

问题：
- 英文缩写太多
- 黑话太多
- 结尾太平

改法：
- 先翻成人话
- 每段最多留一个必须的英文名词
- 最后一段补一个“但问题还没完”的尾钩

## 常见失败 3：图文重复

问题：
- 图上已经写了结论
- 正文又把同一句话复述一遍

改法：
- 图上讲“看到了什么”
- 正文讲“为什么会这样”
