# Page Patterns

## 1. 人物商业题

建议 `4` 张图：
- 图 1：情绪或商业新闻封面
- 图 2：关键证据截图
- 图 3：机制图
- 图 4：总结或互动图

适合：
- 球星带动联盟价值
- 薪资、代言、商业影响力

## 2. 规则解释题

建议 `3` 张图：
- 图 1：最小可懂的封面
- 图 2：数字或结构图
- 图 3：为什么现在会变

适合：
- 工资帽
- 转播权
- 赛制或规则变化

## 3. 争议对撞题

建议 `3-4` 张图：
- 图 1：对撞封面
- 图 2：A 方证据
- 图 3：B 方证据
- 图 4：你的判断 / 互动

适合：
- 谁占便宜
- 为什么大家站队

## 回退规则

- 没有人物，就不要硬塞人物
- 没有证据截图，就不要假装有
- 一张图如果承担两个主任务，先删一个
