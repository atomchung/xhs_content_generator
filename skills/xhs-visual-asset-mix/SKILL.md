# XHS Visual Asset Mix

> **这个 skill 不是默认步骤。**
> 默认情况下，图组分工直接在 `xhs-note-assembly` 中按账号预设完成（图 1 生图封面 / 图 2-4 真人或截图）。
> 只有在素材选择确实需要单独讨论时，才启用这个 skill。

这个 skill 负责决定：
- 每张图该用 `真人图 / 官方截图 / 生图` 的哪一种
- 哪些真人素材最强、该放在哪个位置

不要在这一步细调画风 prompt，那交给 `xhs-image-style-duo`。

## 什么时候用

只在以下情况才单独启用：

- 用户明确在纠结某张图该用真人还是生图
- 这篇明显需要多张证据截图，配比和默认差异大
- 用户手上有多张候选真人照片，需要帮忙挑选和排序
- 用户明确说”图组分工我想重新想”

## 核心原则

### 0. 视觉也要让小白一眼知道“这是什么”

- 首图要能看出主角、事件或冲突，不要只让老粉才认得出来
- 如果这篇在讲规则、钱、平台战争，图里要有能帮助理解的中文信息锚点
- 不要把识别门槛建立在英文缩写上

### 1. 每张图只能承担一个主要任务

主要任务通常只有这几种：
- 拉点击
- 立证据
- 讲机制
- 做总结

### 2. 选择素材类型，不看“高级感”，只看任务匹配

- 真人图：最适合情绪、气场、球星本人、现场感
- 官方截图：最适合证据、公告、平台动作、官方话术
- 生图：最适合封面、概念、机制、抽象关系

如果图上需要补字：
- 优先用中文
- 只留最短、最能帮助理解的一句
- 不要在封面堆英文术语

### 3. 推荐配比

体育知识型帖子默认优先：
- `1 张` 生图封面
- `1-2 张` 真人或官方截图
- `1 张` 生图解释图

### 3.1 当前账号默认

- 不再把“首图到底要不要生图”当成每篇都重问一次的问题
- 对这个账号，首图默认就是生图系统
- 真人图和截图承担：
  - 证据
  - 真实性
  - 官方动作
  - 情绪补强

### 4. 人类必须参与素材选择

默认需要人类提供或拍板：
- 哪张真人图最像“封面级”
- 哪张官方截图最能证明核心论点
- 哪些图可以公开引用，哪些不适合直接用

### 4.1 素材不够时的回退顺序

- 如果没有强真人图：
  图 1 先回退到 `xhs-cover-template + xhs-image-style-duo`
- 如果没有够强的官方截图：
  不要硬凑“证据图”，改成更清楚的机制图，并把证据压力留给正文和来源
- 如果这题本来就没有人物主角：
  不要勉强塞人脸，优先用物件、场馆、屏幕、数字结构做锚点

## 工作流

### 1. 先列故事节点

例如：
- 钩子
- 证据
- 争议
- 机制

### 2. 再给每个节点配素材类型

示例：
- 钩子 -> 生图
- 大谷 / 日本队情绪锚点 -> 真人图
- Netflix WBC 独占事实 -> 官方截图
- 单一入口 / 平台战争 -> 生图

### 3. 如果真人素材不够，再回退到生图

但不要反过来。

先判断有没有比生图更强的真实证据，再决定要不要全生图。

如果图 1 最终是生图：

- 默认先沿用 `xhs-note-assembly` 已经提取好的封面结构
- 只有默认封面结构不适用时，才回到 `xhs-cover-template`
- 再用 `xhs-image-style-duo` 输出网页可直接使用的最终 prompt

### 4. 这一关的人工介入

默认要求人类拍板：
- 封面走哪种生图结构
- 真人图候选哪张最强
- 官方截图用哪张

## 存档约定

如果当前已经有贴文目录，默认把视觉分工和后续图片资产放进同一个贴文工作区：

- 图片策略说明可放在 `demo_posts/<date>-<slug>/prompts/` 或同目录说明文件
- 实际成图放在 `demo_posts/<date>-<slug>/images/`

不要把图片计划散落在根目录。

## 不要这样做

- 不要默认整组都用生图
- 不要让一张图同时承担钩子、证据和机制
- 不要在没有真人素材时假装“全生图也一样”
- 不要在这里开始反复调画风
