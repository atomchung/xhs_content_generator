# XHS Visual Asset Mix

这个 skill 只负责决定：
- 一篇帖子到底要几张图
- 每张图承担什么任务
- 每张图该用 `真人图 / 官方截图 / 生图` 的哪一种

不要在这一步直接细调画风 prompt。

画风细调交给 `xhs-image-style-duo`。

## 什么时候用

- 用户说“真人和生图要并行”
- 用户说“这张该用真人还是生图”
- 用户说“图 2 图 3 图 4 怎么安排”
- 用户要做证据图、截图图、机制图
- 用户已经有故事，但还没锁视觉分工

## 核心原则

### 1. 每张图只能承担一个主要任务

主要任务通常只有这几种：
- 拉点击
- 立证据
- 讲机制
- 做总结

### 2. 选择素材类型，不看“高级感”，只看任务匹配

- 真人图：最适合情绪、气场、球星本人、现场感
- 官方截图：最适合证据、公告、平台动作、官方话术
- 生图：最适合封面、概念、机制、抽象关系

### 3. 推荐配比

体育知识型帖子默认优先：
- `1 张` 生图封面
- `1-2 张` 真人或官方截图
- `1 张` 生图解释图

### 4. 人类必须参与素材选择

默认需要人类提供或拍板：
- 哪张真人图最像“封面级”
- 哪张官方截图最能证明核心论点
- 哪些图可以公开引用，哪些不适合直接用

## 工作流

### 1. 先列故事节点

例如：
- 钩子
- 证据
- 争议
- 机制

### 2. 再给每个节点配素材类型

示例：
- 钩子 -> 生图
- 大谷 / 日本队情绪锚点 -> 真人图
- Netflix WBC 独占事实 -> 官方截图
- 单一入口 / 平台战争 -> 生图

### 3. 如果真人素材不够，再回退到生图

但不要反过来。

先判断有没有比生图更强的真实证据，再决定要不要全生图。

### 4. 这一关的人工介入

默认要求人类拍板：
- 封面是否一定生图
- 真人图候选哪张最强
- 官方截图用哪张

## 输出格式

```markdown
## 图组策略
- 建议张数：
- 建议配比：

## 每张图分工
### 图 1
- 任务：
- 素材类型：
- 为什么：
- 需要人提供什么：

### 图 2
...

## 素材清单
- 真人素材候选：
- 官方截图候选：
- 可直接生图的页：

## 需要人拍板
- 封面路线：
- 真人图选择：
- 官方截图选择：
```

## 不要这样做

- 不要默认整组都用生图
- 不要让一张图同时承担钩子、证据和机制
- 不要在没有真人素材时假装“全生图也一样”
- 不要在这里开始反复调画风
