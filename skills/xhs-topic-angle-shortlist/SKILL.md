# XHS Topic Angle Shortlist

这个 skill 只负责一件事：从热点里挑出真正值得做的小红书故事角度。

不要在这一步直接写完整正文，也不要先做图片。

## 什么时候用

- 用户要蹭热点，但还没锁题
- 用户说“先想几个角度”
- 用户说“哪个更有爆款相”
- 用户只要标题方向或故事入口
- 用户说“先别写正文”

## 输出目标

输出 `3 到 5 个` 可直接进入下一步的角度，每个角度都要说明：
- 为什么现在值得做
- 最强的情绪入口是什么
- 最强的知识点是什么
- 最适合拿什么人或事件做封面
- 为什么中国小红书用户会点

## 工作流

### 1. 先找“能讲成故事”的热点

优先选下面几类：
- 大事件背后的钱、规则、平台、权力
- 一个明星带出的更大行业变化
- 一件争议为什么会引发全民站队
- 一个赛果背后真正重要的结构变化

### 2. 每个候选角度都要同时过 5 个筛子

- 新鲜度：是不是正在热
- 共鸣度：非硬核球迷也能代入吗
- 知识增量：不是刷新闻就能知道吗
- 视觉可讲性：能不能做出强封面和 3-4 张图
- 互动性：用户会不会想站队、判断、补充

### 3. 角度必须是“问题句”或“判断句”

不要给这种：
- `WBC 转播权变化`
- `大谷与 Netflix`

要给这种：
- `网飞为什么愿意为日本 WBC 砸这么多钱？`
- `这不是转播权新闻，而是日本视频入口大战`
- `如果没有大谷，网飞还会不会赌这笔钱？`

### 4. 这一关必须有人拍板

这一步机器只负责缩小选择范围，不负责最后决定。

默认要求人类在下面三件事里拍板：
- 最终选哪个角度
- 是偏争议、偏商业，还是偏人物
- 这一题要不要做成长帖

## 输出格式

```markdown
## 热点池判断
- 当前最值得做的母题：
- 不建议做的方向：

## 角度候选
### 角度 1
- 一句话切角：
- 为什么现在做：
- 情绪入口：
- 知识增量：
- 视觉锚点：
- 互动问题：
- 综合分：

### 角度 2
...

## 推荐
- 第一推荐：
- 第二推荐：

## 需要人拍板
- 选哪个角度：
- 偏争议 / 偏商业 / 偏人物：
- 是否进入 fact pack：
```

## 不要这样做

- 不要直接把新闻标题换一种说法
- 不要先写长正文
- 不要在没锁角度前开始打磨封面
- 不要把“热”误当成“适合做小红书”
