# XHS Topic Angle Shortlist

这个 skill 只负责一件事：从当前热点里挑出真正值得做的小红书题目，并把每个题目拆成多个可选切角。

不要在这一步直接写完整正文，也不要先做图片。

## 什么时候用

- 用户要蹭热点，但还没锁题
- 用户说“先想几个角度”
- 用户说“哪个更有爆款相”
- 用户只要标题方向或故事入口
- 用户说“先别写正文”

不要在这些场景直接用这个 skill，应该先放进 `explorations/`：

- 用户要做一个长期系列
- 用户要探索账号方向、内容支柱或栏目结构
- 用户要测试视觉系统、封面模板或工作流
- 用户要研究参考作者、参考媒体或账号 benchmark
- 用户明确说“先不要落成具体帖子”

## 如果实时信息不完整

- 如果账号页面打不开：
  明确说明，然后退回到本地保存的账号 DNA、过往 review 或用户给的截图
- 如果当前热点搜不到足够强的候选：
  先分成 `已验证当前热点` 和 `可做的常青候选` 两组，不要把旧题伪装成“今天最热”
- 如果用户只给了一个很模糊的方向：
  先输出更窄的母题篮子，再继续切角，不要直接假装已经锁题

## 输出目标

默认输出 `至少 5 个题目`，每个题目都要给出 `至少 3 个切角`。

每个题目都要说明：
- 为什么现在值得做
- 为什么适合这个账号
- 最适合拿什么人或事件做封面
- 为什么中国小红书用户会点
- 小白第一次看到时，怎么在一句话里明白“这是什么”

每个切角都要说明：
- 一句话切角
- 情绪入口
- 知识增量
- 互动问题

## 通用写作约束

### 1. 少用不必要英文，默认按简中读者理解来写

- 题目、切角、解释话术优先用中文，不要把英文缩写当默认常识
- 必须提英文术语时，第一次出现要先写中文解释，再补英文或缩写
- 如果一个题目离开英文缩写就讲不清，说明这个题目还没被翻译成人话，要先重写

### 2. 先给小白入口，再给硬核信息

- 默认读者不懂联赛简称、规则缩写和历史背景
- 每个题目至少要能用一句话说清：`这是什么 + 为什么现在热 + 为什么值得点`
- 切角不是给硬核球迷打暗号，而是要让路人也能顺着点进去

## 工作流

### 0. 先复看账号最近发过的内容

在给任何题目前，必须先看用户提供的小红书账号或最近笔记。

- 优先看最近 `10-20` 条公开可见内容
- 记录：高频人物、联赛、商业题、历史题、女子体育题、标题句法
- 如果页面打不开，要明确说明没法实时查看，并退回到本地保存的账号 DNA 或用户给的截图
- 不要跳过这一步，除非用户明确说“不要参考账号历史”

### 1. 再搜“当前正在热”的体育和体育商业热点

至少覆盖下面两类来源：

- 体育热点：联盟/赛事/球员/官方赛程/主流体育媒体
- 体育商业：版权、估值、赞助、转播、平台竞争、女子体育商业化

优先搜索：
- 官方或一级来源
- AP / ESPN / NCAA / MLB / NBA / WNBA / NFL / F1 / IOC 等
- Front Office Sports / Sportico / Boardroom 等体育商业来源

如果用户提到“最近 / 最新 / 今天 / 现在”，必须写绝对日期。

### 2. 先找“能讲成故事”的热点

优先选下面几类：
- 大事件背后的钱、规则、平台、权力
- 一个明星带出的更大行业变化
- 一件争议为什么会引发全民站队
- 一个赛果背后真正重要的结构变化

### 3. 每个候选题目都要同时过 5 个筛子

- 新鲜度：是不是正在热
- 共鸣度：非硬核球迷也能代入吗
- 知识增量：不是刷新闻就能知道吗
- 视觉可讲性：能不能做出强封面和 3-4 张图
- 互动性：用户会不会想站队、判断、补充

### 4. 每个题目下至少给 3 个切角

不要只给 1 个角度。

优先拆成：
- 偏争议
- 偏商业
- 偏人物

如果题目天然适合，也可以换成：
- 偏规则
- 偏历史
- 偏平台战争

### 5. 切角必须是“问题句”或“判断句”

不要给这种：
- `WBC 转播权变化`
- `大谷与 Netflix`

要给这种：
- `网飞为什么愿意为日本 WBC 砸这么多钱？`
- `这不是转播权新闻，而是日本视频入口大战`
- `如果没有大谷，网飞还会不会赌这笔钱？`

同时要满足：
- 不懂这个赛事的人，也能从句子里知道它大概在讲什么
- 不靠英文缩写堆神秘感

### 6. 这一关必须有人拍板

这一步机器只负责缩小选择范围，不负责最后决定。

默认要求人类在下面三件事里拍板：
- 最终选哪个题目
- 每个题目下选哪个切角
- 是偏争议、偏商业，还是偏人物
- 这一题要不要做成长帖

### 7. 一旦锁题，立刻建贴文目录

如果用户决定继续做某个题目，默认把后续资产放进同一个贴文目录：

- `demo_posts/<date>-<slug>/research/research.md`
- `demo_posts/<date>-<slug>/research/fact_pack.md`
- `demo_posts/<date>-<slug>/text/post.md`
- `demo_posts/<date>-<slug>/prompts/`
- `demo_posts/<date>-<slug>/images/`

如果目录还不存在，优先创建它，再继续后面的 skill。不要把研究内容只留在对话里。

### 8. 明确区分“探索”和“发想”

这里的“发想”是指：
- 已经围绕某一个事件、人物或问题
- 正在决定这一篇要怎么切
- 很可能会进入正文、图组和发布

这种情况应该进入：
- `demo_posts/<date>-<slug>/`

这里的“探索”是指：
- 还在想一个系列值不值得做
- 还在比较多种视觉语言或封面模板
- 还在整理参考作者和账号方向
- 这一轮产出会影响很多后续帖子，而不是只影响一篇

这种情况应该进入：
- `explorations/series/`
- `explorations/visuals/`
- `explorations/workflows/`

不要把跨多篇帖子的系统级思考直接塞进单篇 `demo_posts/`。

## 不要这样做

- 不要直接把新闻标题换一种说法
- 不要只给一个“最热母题”
- 不要少于 5 个题目
- 不要让每个题目只有 1 个切角
- 不要在没复看账号和没搜当前热点前就开始列题
- 不要先写长正文
- 不要在没锁角度前开始打磨封面
- 不要把“热”误当成“适合做小红书”
