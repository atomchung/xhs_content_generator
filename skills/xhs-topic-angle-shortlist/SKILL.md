# XHS Topic Angle Shortlist

这个 skill 只负责一件事：从当前热点里挑出真正值得做的小红书题目，并把每个题目拆成多个可选切角。

不要在这一步直接写完整正文，也不要先做图片。

## 什么时候用

- 用户要蹭热点，但还没锁题
- 用户说“先想几个角度”
- 用户说“哪个更有爆款相”
- 用户只要标题方向或故事入口
- 用户说“先别写正文”

## 输出目标

默认输出 `至少 5 个题目`，每个题目都要给出 `至少 3 个切角`。

每个题目都要说明：
- 为什么现在值得做
- 为什么适合这个账号
- 最适合拿什么人或事件做封面
- 为什么中国小红书用户会点

每个切角都要说明：
- 一句话切角
- 情绪入口
- 知识增量
- 互动问题

## 工作流

### 0. 先复看账号最近发过的内容

在给任何题目前，必须先看用户提供的小红书账号或最近笔记。

- 优先看最近 `10-20` 条公开可见内容
- 记录：高频人物、联赛、商业题、历史题、女子体育题、标题句法
- 如果页面打不开，要明确说明没法实时查看，并退回到本地保存的账号 DNA 或用户给的截图
- 不要跳过这一步，除非用户明确说“不要参考账号历史”

### 1. 再搜“当前正在热”的体育和体育商业热点

至少覆盖下面两类来源：

- 体育热点：联盟/赛事/球员/官方赛程/主流体育媒体
- 体育商业：版权、估值、赞助、转播、平台竞争、女子体育商业化

优先搜索：
- 官方或一级来源
- AP / ESPN / NCAA / MLB / NBA / WNBA / NFL / F1 / IOC 等
- Front Office Sports / Sportico / Boardroom 等体育商业来源

如果用户提到“最近 / 最新 / 今天 / 现在”，必须写绝对日期。

### 2. 先找“能讲成故事”的热点

优先选下面几类：
- 大事件背后的钱、规则、平台、权力
- 一个明星带出的更大行业变化
- 一件争议为什么会引发全民站队
- 一个赛果背后真正重要的结构变化

### 3. 每个候选题目都要同时过 5 个筛子

- 新鲜度：是不是正在热
- 共鸣度：非硬核球迷也能代入吗
- 知识增量：不是刷新闻就能知道吗
- 视觉可讲性：能不能做出强封面和 3-4 张图
- 互动性：用户会不会想站队、判断、补充

### 4. 每个题目下至少给 3 个切角

不要只给 1 个角度。

优先拆成：
- 偏争议
- 偏商业
- 偏人物

如果题目天然适合，也可以换成：
- 偏规则
- 偏历史
- 偏平台战争

### 5. 切角必须是“问题句”或“判断句”

不要给这种：
- `WBC 转播权变化`
- `大谷与 Netflix`

要给这种：
- `网飞为什么愿意为日本 WBC 砸这么多钱？`
- `这不是转播权新闻，而是日本视频入口大战`
- `如果没有大谷，网飞还会不会赌这笔钱？`

### 6. 这一关必须有人拍板

这一步机器只负责缩小选择范围，不负责最后决定。

默认要求人类在下面三件事里拍板：
- 最终选哪个题目
- 每个题目下选哪个切角
- 是偏争议、偏商业，还是偏人物
- 这一题要不要做成长帖

## 不要这样做

- 不要直接把新闻标题换一种说法
- 不要只给一个“最热母题”
- 不要少于 5 个题目
- 不要让每个题目只有 1 个切角
- 不要在没复看账号和没搜当前热点前就开始列题
- 不要先写长正文
- 不要在没锁角度前开始打磨封面
- 不要把“热”误当成“适合做小红书”
