# Style Profiles

这份参考定义的是 `风格包`，不是固定结果。

使用方式：

- 先选 `1 个主风格`
- 再选 `1 个对照风格`
- 两者共用同一套故事骨架

## 1. Anime Cover

目标：
- 热血运动动画封面
- 名场面暂停帧
- 强动作、强主角、干净背景

适合：
- 首图
- 对峙感
- 人物升咖题
- 情绪强、动作强的故事

避免：
- 背景脏乱
- 动作像摆拍
- 只有懂梗的人才看得懂

## 2. Game Cinematic

目标：
- 欧美游戏动画电影感
- 立体、昂贵、强戏剧光影
- 更适合“巨星改变联盟”的人物题

适合：
- 商业新闻人物封面
- 球星价值跃迁
- 联盟结构变化里的关键人物

避免：
- 低质 3D 感
- 过写实照片感
- 背景比人物更抢

## 3. Editorial Collage

目标：
- 体育商业杂志拼贴
- 人物、数字、屏幕、场馆、剪报共同服务一个结论

适合：
- 薪资
- 转播
- 扩军
- 平台战争

避免：
- 信息太满
- 小元素过多
- 既不够真实也不够设计

## 4. Minimal Data Poster

目标：
- 极简数据海报
- 数字和结构是主角
- 人物可以弱化成轮廓或次级元素

适合：
- 规则解释
- 工资帽 / 转播费 / 结构变化
- 第二张或第三张解释图

避免：
- 把它做成 PPT
- 文案太多
- 花哨科技风

## 5. Mascot Q

目标：
- 运动吉祥物化
- 更轻、更可爱、更像可收藏角色卡

适合：
- 年轻化
- 轻梗
- IP 化尝试

避免：
- 普通 chibi
- 复杂背景
- 大头真人感
