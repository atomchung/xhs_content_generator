# Style Profiles

这份参考定义的是 `风格包`，不是固定结果。

使用方式：

- 先选 `1 个主风格`
- 再选 `1 个对照风格`
- 两者共用同一套故事骨架

## 1. Anime Cover

目标：
- 热血运动动画封面
- 名场面暂停帧
- 强动作、强主角、干净背景

适合：
- 首图
- 对峙感
- 人物升咖题
- 情绪强、动作强的故事

避免：
- 背景脏乱
- 动作像摆拍
- 只有懂梗的人才看得懂

## 2. Game Cinematic

目标：
- 欧美游戏动画电影感
- 立体、昂贵、强戏剧光影
- 更适合“巨星改变联盟”的人物题

适合：
- 商业新闻人物封面
- 球星价值跃迁
- 联盟结构变化里的关键人物

避免：
- 低质 3D 感
- 过写实照片感
- 背景比人物更抢

## 3. Editorial Collage

目标：
- 体育商业杂志拼贴
- 人物、数字、屏幕、场馆、剪报共同服务一个结论

适合：
- 薪资
- 转播
- 扩军
- 平台战争

避免：
- 信息太满
- 小元素过多
- 既不够真实也不够设计

## 4. Minimal Data Poster

目标：
- 极简数据海报
- 数字和结构是主角
- 人物可以弱化成轮廓或次级元素

适合：
- 规则解释
- 工资帽 / 转播费 / 结构变化
- 第二张或第三张解释图

避免：
- 把它做成 PPT
- 文案太多
- 花哨科技风

## 5. Mascot Q

目标：
- 运动吉祥物化
- 更轻、更可爱、更像可收藏角色卡

适合：
- 年轻化
- 轻梗
- IP 化尝试

避免：
- 普通 chibi
- 复杂背景
- 大头真人感

## 6. Watercolor Ink Sketch（水墨水彩速写）

状态：✅ **已通过生成测试，可以用于产线**

目标：
- 人物用黑白墨线精细刻画（线描 + 交叉排线），背景用松散水彩色块渲染
- 两层对比是核心视觉张力：精确灰阶人物 vs. 流动彩色水彩背景
- 编辑插画、手作感、不是数字感

适合：
- 文艺 / 故事 / 个人成长类人物帖
- 球星故事、球员介绍、生涯高光回顾（非致敬题）
- 希望「慢下来读」的帖子而非「一眼炸」的帖子

避免：
- NBA 动作题（已被 canonical comic break-out 压制）
- 需要瞬间 CTR 的硬商业题
- 背景画具体物件（会稀释水彩层）

详细 prompt 模板和生成测试记录：`explorations/visuals/sports-illustration-styles.md` Style A 段

## 7. Ink Wash Silhouette（水墨剪影）

状态：🟡 **备选，待测试** — 参考 [issue #16](https://github.com/atomchung/xhs_content_generator/issues/16)

目标：
- 不用线描，用墨色浓淡直接塑造剪影
- 飞白 / 枯笔效果表达速度
- 大面积留白 + 极少量彩色点缀

适合（假说）：
- 致敬 / 退役 / 生涯回顾
- 需要高级感和东方美学调性
- 差异化封面（避免和其他号撞视觉）

避免：
- 强动作题（剪影无法表达细节动作）
- 多人构图
- 信息密度高的题

**未实战前不要直接推给用户**，要用时先出测试再决定。

## 8. Risograph Duotone（双色印刷风）

状态：🟡 **备选，待测试** — 参考 [issue #16](https://github.com/atomchung/xhs_content_generator/issues/16)

目标：
- 模拟 Risograph 双色叠印效果——整张图只用两个颜色叠加
- 颗粒质感 + 错位套色产生复古现代感
- 人物作为图形元素存在，不是写实主体

适合（假说）：
- 系列帖子统一视觉（换两个颜色即可变体）
- 设计感强的封面
- 商业题的辅助图而非首图

避免：
- 需要表情细节的人物特写
- 高写实要求的题
- NBA 球员动作题

**未实战前不要直接推给用户**，要用时先出测试再决定。
