# Prompt Polish Rules

## 一、先锁动作，再谈背景

如果动作不成立，再华丽的背景都救不了图。

先写：

- 主角是谁
- 正在做什么
- 镜头从哪里看
- 最紧绷的身体节点在哪

再写背景。

## 二、背景只承担说明，不承担主戏

背景最多做三件事：

- 说明地点
- 说明冲突阵营
- 增加气氛

不要让背景讲完整故事。

## 三、Anime Cover 的重点

- 动作必须像“名场面暂停帧”
- 主角要像封面人物
- 背景必须干净
- 冲突最好左右对撞或前后压迫

## 四、Game Cinematic 的重点

- 人物气场比花哨风格更重要
- 光影要高级，但不能变成照片感
- 最适合“人物带动产业变化”这种题

## 五、Editorial Collage 的重点

- 人物、数字、屏幕、场馆只服务一个结论
- 拼贴是为了增强信息密度，不是为了做杂
- 如果元素太多，先删次要图层

## 六、Minimal Data Poster 的重点

- 数字层级比装饰更重要
- 适合第二张或第三张解释图
- 如果一眼看不出“涨、跌、对比”，就要重写

## 七、Mascot Q 的重点

- 先想“它像什么吉祥物”
- 再想“它拿什么道具”
- 最后才想背景

如果 Q 版不可爱，先减背景，不要先加细节。

## 八、频繁改背景时的顺序

固定流程：

1. subject anchor
2. background prompt
3. final cover prompt

如果背景改了：

- 不重写 subject anchor
- 只改 background prompt
- 再刷新 final cover prompt

## 九、最容易出错的点

- Anime：背景太满，动作太弱
- Game Cinematic：太像廉价 3D 游戏立绘
- Editorial：元素太多，拼不出主结论
- Minimal Data：像 PPT，不像海报
- Q 版：元素太多，不够像吉祥物
- 两者共同：主角不够一眼看懂
