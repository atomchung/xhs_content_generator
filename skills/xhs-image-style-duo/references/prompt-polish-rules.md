# Prompt Polish Rules

## 一、先锁动作，再谈背景

如果动作不成立，再华丽的背景都救不了图。

先写：

- 主角是谁
- 正在做什么
- 镜头从哪里看
- 最紧绷的身体节点在哪

再写背景。

## 二、背景只承担说明，不承担主戏

背景最多做三件事：

- 说明地点
- 说明冲突阵营
- 增加气氛

不要让背景讲完整故事。

## 三、Anime Cover 的重点

- 动作必须像“名场面暂停帧”
- 主角要像封面人物
- 背景必须干净
- 冲突最好左右对撞或前后压迫

## 四、Mascot Q 的重点

- 先想“它像什么吉祥物”
- 再想“它拿什么道具”
- 最后才想背景

如果 Q 版不可爱，先减背景，不要先加细节。

## 五、频繁改背景时的顺序

固定流程：

1. subject anchor
2. background prompt
3. final cover prompt

如果背景改了：

- 不重写 subject anchor
- 只改 background prompt
- 再刷新 final cover prompt

## 六、最容易出错的点

- Anime：背景太满，动作太弱
- Q 版：元素太多，不够像吉祥物
- 两者共同：主角不够一眼看懂
