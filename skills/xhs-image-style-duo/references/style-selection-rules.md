# Style Selection Rules

默认先判断这张图的主任务。

## 1. 人物主角题

优先：
- `Game Cinematic`
- `Anime Cover`

适合：
- 球星升咖
- 人物带动联盟变化
- 首图点击

## 2. 商业新闻题

优先：
- `Editorial Collage`
- `Minimal Data Poster`

适合：
- 薪资
- 转播
- 扩军
- 平台战争

## 3. 轻松角色化题

优先：
- `Mascot Q`
- `Anime Cover`

适合：
- 更年轻化
- 更轻、更可爱
- 有拟人角色空间

## 4. 如果拿不准

先问：
- 这张图是卖人物，还是卖结构？

答案如果偏：
- 人物 -> `Game Cinematic / Anime Cover`
- 结构 -> `Editorial Collage / Minimal Data Poster`
