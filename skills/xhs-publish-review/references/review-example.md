# Publish Review Example

下面这份不是完整内容，而是最小合格结构。

## 差异清单

### 文案
- 差异：开头从背景说明改成一句判断
- 归因：发布版更适合小红书首屏阅读
- 小白可读性：提升，因为前两句就能知道主题
- 下次规则：先写判断句，再补背景

### 图片
- 差异：首图保留情绪，后页换成真实截图和证据图
- 归因：可信度提升，避免整组都像 AI 想象图
- 小白识别度：提升，因为“这事是真的发生过”更直观
- 下次规则：封面可以做情绪，后页必须给证据

### 流程
- 差异：图组分工在后期才决定
- 归因：前期探索太散，导致图片反复返工
- 下次规则：先锁每张图任务，再决定素材类型

## 新的工作流
1. 先锁只讲一个故事
2. 再锁图组任务
3. 最后才细调封面和正文

## 必须人工介入的点
- 最终首图选哪张
- 哪个判断句最适合放开头

## 假设更新
- 新增：人物商业题最适合“情绪封面 + 证据后页”
- 下次要测：纯机制题是否还需要强人物封面
