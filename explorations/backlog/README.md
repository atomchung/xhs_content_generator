# Backlog

Use this folder for cross-post topic and angle backlog management.

This is the upstream layer before one idea becomes one concrete post workspace.

Store here:

- reusable topic ideas
- possible angles that are not yet one final story line
- importance / priority updates
- next review dates
- notes about why something is `active now`, `watch later`, or `parked`

Promotion rule:

1. Choose one topic worth researching now.
2. Create `demo_posts/<date>-<slug>/`.
3. Build `research/fact_pack.md`.
4. Turn the research into `research/story_spine.md`.

Do not store the full per-post research file here.
