# Explorations

This folder stores work that is not yet one concrete Xiaohongshu post workspace.

Use it for:

- topic-series planning that may generate many posts
- visual-system experiments and cover directions
- workflow and prompt experiments
- creator benchmarking and account-direction studies

Do not use it for:

- the working folder of one post candidate
- the final draft and review of one published post

## Structure

- `backlog/`
  Cross-post topic backlog, possible-angle backlog, and importance tracking.
- `series/`
  Multi-post topic systems, franchises, and long-term content lanes.
- `visuals/`
  Cover systems, style tests, reusable layouts, and image-direction experiments.
- `workflows/`
  Process experiments, production checklists, and prompt-method tests.

## Promotion rule

When one exploration becomes one concrete post candidate, create a folder under:

- `demo_posts/<date>-<slug>/`

Keep the exploration as the upstream thinking layer, and keep the post workspace as the downstream execution layer.

## Clear boundary with post ideation

Use `explorations/` when you are still deciding a system:

- which topics should stay active in backlog
- which possible angles should be raised or parked
- what series to build
- what visual language to reuse
- what workflow to standardize
- which creators or media brands to benchmark

Use `demo_posts/` when you are already deciding one post:

- which angle this one post should use
- whether this one post is worth drafting
- what title,正文,图组 this one post should have

Rule:

- `探索` = one idea may influence many future posts
- `发想` = one idea is already becoming one specific post
