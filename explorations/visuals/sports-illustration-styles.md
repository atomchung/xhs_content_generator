# Sports Illustration Styles Exploration

来源：Xiaohongshu / Instagram 运动插画帐号
目的：分析三种现有风格包未覆盖的插画风格，评估是否值得纳入 style-profiles

---

## Style A — Watercolor Ink Sketch（水墨水彩速写）

### 风格描述

人物用黑白墨线精细刻画（线描 + 交叉排线），背景用松散的水彩色块渲染。
两层的对比是核心视觉张力：精确的灰阶人物 vs. 流动的彩色水彩背景。

关键特征：
- 人物：黑白灰墨线，有笔触感，线条干净但不死板
- 背景：柔和粉彩水彩渐晕（薄荷绿、粉、桃、鹅黄）
- 人物不上彩色，靠墨线自身完成光影
- 背景不画具体物件，只有颜色和晕染
- 整体像运动杂志编辑插画或高级速写本
- 构图简洁，一人一球，留白多

### 与现有风格包的关系

不属于现有任何一个风格。Anime Cover 是干净动画感，Game Cinematic 是电影光影感，两者都不是这种手绘笔触 + 水彩松散感。

### 适合场景

- 人物特写、运动员介绍
- 调性更文艺、更"手作感"的首图
- 适合不想走热血路线但仍需人物焦点的题目
- 球星故事、个人成长类

### 不适合

- 需要强烈动作冲击的热血场景
- 商业数据、机制解释
- 多人复杂构图

### Prompt

```text
Black-and-white ink illustration of a tall basketball player in a Spurs jersey, dribbling low with one hand, confident forward-leaning stance, rendered entirely in grayscale ink with visible cross-hatching and sketch-like line work. Background is loose abstract watercolor washes in soft pastel tones — mint green, blush pink, warm peach, and pale yellow — bleeding into each other with no hard edges. The figure is precise and detailed while the background is painterly and fluid. Sports editorial illustration feel, strong contrast between monochrome subject and colorful wash background, vertical 3:4 composition, generous negative space, no readable text, no logos, no watermarks.
```

## Style B — Dynamic Comic Art（动态漫画插画）

### 风格描述

大胆的美式漫画风格，人物比例略微夸张，动作极度动态。
色彩饱和、光影戏剧化，有强烈的漫画书能量。

关键特征：
- 人物：夸张的肌肉线条和动态姿势，比例略大于真实
- 色调：暗色系为主（深紫、品红），配饱和亮色点缀（红色篮球）
- 强边缘光 / 轮廓光（rim light），让人物从暗背景中弹出
- 动作线和速度感，构图有漫画分镜的冲击力
- 多人构图也能保持清晰层次（前景人物 + 后景人物）
- 整体像 NBA 官方概念插画或球鞋广告艺术

### 与现有风格包的关系

和 Game Cinematic 最接近，但更偏漫画 / 卡通风，不是 3D 游戏感。
比 Anime Cover 更粗犷、更美式，线条更厚重，不是日式动画的干净感。

### 适合场景

- 双人对决、球队组合、赛季预告
- 需要"炸裂感"和"力量感"的首图
- 球星搭档、新赛季阵容
- 适合男性向运动帐号

### 不适合

- 文艺、安静调性
- 数据解释、商业分析
- 需要写实感或照片感的场景

### Prompt

```text
Bold dynamic comic-book style illustration of two basketball players in dark San Antonio Spurs jerseys, one tall player leaping from above with exaggerated powerful motion dribbling a bright red basketball with one hand, another player charging forward from below also controlling a red basketball, both figures with slightly exaggerated muscular proportions and intense facial expressions. Dramatic warm lighting with deep purple and magenta tones, strong rim lighting outlining both figures against a dark gradient background, dynamic action lines and motion energy, comic-book impact composition with clear foreground and background layering. Bold saturated colors, thick confident line work, high-energy sports comic art style, vertical 3:4 composition, no readable text, no logos, no watermarks.
```

## Style C — Anime Crossover / Pop Culture Mashup（动漫跨界混搭）

### 风格描述

将真实运动员放入知名动漫 / 流行文化 IP 的世界观中。
不是简单的 cosplay，而是把运动员"转生"成那个 IP 的角色，同时保留运动员的辨识度。

关键特征：
- 核心概念：运动员 × 知名 IP 角色融合（例：Wemby × Avatar 降世神通）
- 画风跟随目标 IP 的美术风格（Avatar 风 = 美式动画 + 东方元素）
- 色调统一且极简（灰色系 + 白色发光点缀）
- 人物穿着 IP 角色的服装（僧袍），但保留运动员的身体特征（身高、体型）
- 场景和特效来自 IP 世界观（气宗悬浮、风元素）
- 构图有仪式感和电影感，不是搞笑恶搞
- 高传播力：粉丝向 + 体育向双重吸引

### 与现有风格包的关系

完全不在现有五个风格中。这不是一种"画法"风格，而是一种"概念"风格——
核心是文化混搭（crossover concept），画法会随目标 IP 变化。

### 适合场景

- 球星个人 IP 强化（绰号、人设、梗）
- 高传播力的粉丝向内容
- 赛季开始 / 全明星 / 特殊时刻的趣味封面
- 帐号涨粉内容、分享型内容

### 不适合

- 严肃新闻
- 商业分析
- 需要通用性的首图（非粉丝可能看不懂 IP 梗）

### Prompt

```text
Anime crossover illustration of a very tall basketball player reimagined as an Avatar: The Last Airbender airbender monk, seated in floating lotus meditation pose hovering above the ground, eyes closed in peaceful concentration, wearing traditional gray monk robes with a draped shoulder wrap, bald head with a glowing white airbender arrow marking. Arms extended outward in a meditative mudra position, the figure radiates calm power. Below the floating figure, a circular swirling airbending wind pattern glows white against the floor. Muted monochromatic gray color palette with white luminous accents for the bending effects. Clean vertical composition with a subtle gray column behind the figure, cinematic and reverent atmosphere, anime-influenced Western animation art style, vertical 3:4 composition, no readable text, no logos, no watermarks.
```

## 与现有风格包的差距总结

| 现有风格 | 核心 | 这三个新风格的差异 |
|---|---|---|
| Anime Cover | 日式热血动画封面 | Style A 是手绘水墨，Style C 是跨 IP 混搭 |
| Game Cinematic | 欧美游戏电影感 | Style B 更偏漫画而非 3D 游戏 |
| Editorial Collage | 商业杂志拼贴 | 三个新风格都是纯人物插画，不含数据 |
| Minimal Data Poster | 极简数据海报 | 无交集 |
| Mascot Q | 可爱吉祥物 | 无交集 |

## 是否值得纳入 style-profiles

### Style A — Watercolor Ink Sketch
**建议：可纳入。** 填补了"文艺手绘感"的空缺，适合人物故事但不想走热血路线的题目。
mode 建议：`hero`（仍以单人物为核心）

### Style B — Dynamic Comic Art
**建议：可作为 Game Cinematic 的变体或独立风格。** 如果帐号经常做双人 / 多人动态构图，值得独立。
mode 建议：`hero`

### Style C — Anime Crossover
**建议：先不纳入 style-profiles，作为 special occasion 用法。** 因为这不是一种固定画法，每次需要指定目标 IP，prompt 变化大，不适合自动化流程。适合手动出 prompt。
